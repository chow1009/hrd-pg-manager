
HRD PG MANAGER — ANDROID EDITION
================================

This is a phone-friendly, installable web version using the RentOk report as its starting data.

Imported records:
- 265 tenant records
- Properties: HRD Hostel s, HRD Women's PG, Hrd Men's PG 2

IMPORTANT:
This edition is an Android-friendly browser app. It is NOT yet a cloud multi-user system.
The data included here is a copy of the RentOk report used to create the app.
Sensitive Aadhaar/bank/document fields are not exposed in the app.

FASTEST WAY TO USE IT ON ANDROID:
1. Upload this folder to a web host that gives you HTTPS.
2. Open the HTTPS link in Chrome on Android.
3. Use Chrome menu → Add to Home screen / Install app.
4. The app will open like an Android app.
